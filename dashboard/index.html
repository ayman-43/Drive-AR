A 3-agent AI pipeline that writes the paper first with placeholders, runs real GPU experiments, then blocks submission if any unverified claim survives. No more hallucinated benchmarks.

The Pipeline
3 agents. 3 hours. 1 verified paper.
Each agent owns one domain and never crosses into another.
1
🧠 master agent
Orchestrates the sprint. Owns the clock and all decisions. Reads the research plan, assigns tasks, unblocks teammates.

Never runs code or edits LaTeX.
→
2
⚗️ experiment agent
Owns the GPU. Runs Python benchmarks. Writes verified numbers to ralph/results/*.json.

Never touches the LaTeX paper.
→
3
✍️ writing agent
Owns the LaTeX. Drafts with \ph{} guesses first. Replaces them with \phm{} verified values from JSON.

Never runs code.
The Core Idea
Two macros that guarantee paper integrity
Written directly into LaTeX — the paper itself is the contract.
❌ \ph{guess}
Unevidenced Placeholder
Used when the researcher knows a number is needed but hasn't measured it yet. This is a hard blocker — the audit fails if any \ph{} survives to submission.
% In the paper draft:
Peak GPU memory: \ph{guessed ~22 GB}

% Audit output:
[BLOCK] 1 unmeasured \ph{} placeholder
✅ \phm{key}{value}
Measured & Verified Metric
Used after the experiment agent produces a JSON result. The verifier checks that key exists in the JSON and the value matches exactly. Paper can only compile once all are verified.
% In the paper (after experiment ran):
Speedup: \phm{speedup}{1.38}×

% ralph/results/headline_7b.json:
{ "speedup": "1.38" } ✓ match
